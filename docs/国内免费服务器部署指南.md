## 部署步骤

### 📋 前置准备

1. **获取服务器**
   - 按照上述方案领取免费服务器
   - 记录服务器 IP 地址

2. **准备文件**
   - 确保项目已推送到 GitHub/Gitee
   - 准备好数据库初始化脚本：`db/init.sql`

### 🚀 方法一：Docker 一键部署（推荐）

#### 步骤 1：连接服务器

```bash
# Windows 使用 PowerShell 或 CMD
ssh root@你的服务器IP

# 输入密码（输入时不会显示，直接输入后回车）
```

#### 步骤 2：安装 Docker 和 Docker Compose

```bash
# 更新系统
apt update && apt upgrade -y

# 安装 Docker
curl -fsSL https://get.docker.com -o get-docker.sh
sh get-docker.sh

# 启动 Docker
systemctl start docker
systemctl enable docker

# 安装 Docker Compose
curl -L "https://github.com/docker/compose/releases/download/v2.20.0/docker-compose-$(uname -s)-$(uname -m)" -o /usr/local/bin/docker-compose
chmod +x /usr/local/bin/docker-compose

# 验证安装
docker --version
docker-compose --version
```

#### 步骤 3：克隆项目

```bash
# 安装 Git
apt install git -y

# 克隆项目（替换为你的仓库地址）
git clone https://github.com/你的用户名/libra-library-system-.git
cd libra-library-system-
```

#### 步骤 4：配置环境变量

```bash
# 编辑 docker-compose.yml，修改环境变量
nano docker-compose.yml
```

修改以下内容：
```yaml
environment:
  SPRING_DATASOURCE_URL: jdbc:mysql://libra-db:3306/libra_bms?useSSL=false&allowPublicKeyRetrieval=true&serverTimezone=UTC
  SPRING_DATA_REDIS_HOST: libra-redis
  JWT_SECRET: libra-bms-secret-key-libra-bms-secret-key-libra-bms
  SPRING_PROFILES_ACTIVE: mysql
  PORT: 8080
```

#### 步骤 5：启动服务

```bash
# 构建并启动所有服务
docker-compose up -d

# 查看日志
docker-compose logs -f

# 查看服务状态
docker-compose ps
```

#### 步骤 6：初始化数据库

```bash
# 等待 MySQL 启动（约30秒）
sleep 30

# 执行数据库初始化脚本
docker exec -i libra-db mysql -uroot -proot libra_bms < db/init.sql

# （可选）添加测试数据
docker exec -i libra-db mysql -uroot -proot libra_bms < db/seed.sql
```

#### 步骤 7：配置防火墙

```bash
# 开放 8080 端口（阿里云/腾讯云还需要在控制台配置安全组）
ufw allow 8080/tcp
ufw enable
```

**⚠️ 重要**：还需要在云服务器控制台配置安全组规则：
- **阿里云**：ECS 控制台 → 安全组 → 添加规则：端口 8080，协议 TCP，源 0.0.0.0/0
- **腾讯云**：轻量服务器控制台 → 防火墙 → 添加规则：端口 8080，协议 TCP

#### 步骤 8：测试访问

```bash
# 在浏览器中访问
http://你的服务器IP:8080/swagger-ui.html
```

如果能看到 Swagger 文档，说明部署成功！

### 🔧 方法二：手动部署（不使用 Docker）

#### 步骤 1：安装 Java 21

```bash
# 更新系统
apt update && apt upgrade -y

# 安装 Java 21
apt install openjdk-21-jdk -y

# 验证安装
java -version
```

#### 步骤 2：安装 MySQL 8.0

```bash
# 安装 MySQL
apt install mysql-server -y

# 启动 MySQL
systemctl start mysql
systemctl enable mysql

# 配置 MySQL root 密码
mysql_secure_installation
# 按提示设置密码，其他选项选择 Y

# 创建数据库
mysql -u root -p
```

在 MySQL 中执行：
```sql
CREATE DATABASE libra_bms CHARACTER SET utf8mb4 COLLATE utf8mb4_unicode_ci;
exit;
```

#### 步骤 3：安装 Redis

```bash
# 安装 Redis
apt install redis-server -y

# 启动 Redis
systemctl start redis
systemctl enable redis
```

#### 步骤 4：安装 Maven

```bash
# 安装 Maven
apt install maven -y

# 验证安装
maven -version
```

#### 步骤 5：构建项目

```bash
# 克隆项目
git clone https://github.com/你的用户名/libra-library-system-.git
cd libra-library-system-

# 构建项目
mvn clean package -DskipTests
```

#### 步骤 6：初始化数据库

```bash
# 执行初始化脚本
mysql -u root -p libra_bms < db/init.sql

# （可选）添加测试数据
mysql -u root -p libra_bms < db/seed.sql
```

#### 步骤 7：配置环境变量

创建配置文件：
```bash
nano /etc/libra-bms.env
```

添加内容：
```bash
SPRING_PROFILES_ACTIVE=mysql
SPRING_DATASOURCE_URL=jdbc:mysql://localhost:3306/libra_bms?useSSL=false&allowPublicKeyRetrieval=true&serverTimezone=UTC
SPRING_DATASOURCE_USERNAME=root
SPRING_DATASOURCE_PASSWORD=你的MySQL密码
SPRING_DATA_REDIS_HOST=localhost
SPRING_DATA_REDIS_PORT=6379
JWT_SECRET=libra-bms-secret-key-libra-bms-secret-key-libra-bms
PORT=8080
```

#### 步骤 8：启动应用

```bash
# 复制 jar 包
cp libra-admin/target/libra-admin.jar /opt/libra-bms/

# 创建启动脚本
nano /opt/libra-bms/start.sh
```

添加内容：
```bash
#!/bin/bash
source /etc/libra-bms.env
java -Xms512m -Xmx1024m -jar /opt/libra-bms/libra-admin.jar
```

```bash
# 添加执行权限
chmod +x /opt/libra-bms/start.sh

# 启动应用
/opt/libra-bms/start.sh
```

#### 步骤 9：配置 systemd 服务（可选，实现开机自启）

```bash
# 创建服务文件
nano /etc/systemd/system/libra-bms.service
```

添加内容：
```ini
[Unit]
Description=Libra Library Management System
After=network.target mysql.service redis.service

[Service]
Type=simple
User=root
EnvironmentFile=/etc/libra-bms.env
ExecStart=/usr/bin/java -Xms512m -Xmx1024m -jar /opt/libra-bms/libra-admin.jar
Restart=always
RestartSec=10

[Install]
WantedBy=multi-user.target
```

```bash
# 重载 systemd
systemctl daemon-reload

# 启动服务
systemctl start libra-bms

# 设置开机自启
systemctl enable libra-bms

# 查看状态
systemctl status libra-bms
```

## 常见问题

### ❌ 问题 1：服务器内存不足

**症状**：应用启动失败，提示 OutOfMemoryError

**解决**：
1. 检查服务器内存：`free -h`
2. 如果内存不足，可以：
   - 减少 Java 堆内存：修改 `JAVA_OPTS` 为 `-Xms256m -Xmx512m`
   - 或者升级服务器配置

### ❌ 问题 2：无法访问 8080 端口

**症状**：浏览器无法访问 `http://服务器IP:8080`

**解决**：
1. 检查防火墙：`ufw status`
2. 检查安全组规则（阿里云/腾讯云控制台）
3. 检查应用是否运行：`docker-compose ps` 或 `systemctl status libra-bms`
4. 检查端口监听：`netstat -tlnp | grep 8080`

### ❌ 问题 3：数据库连接失败

**症状**：应用日志显示数据库连接错误

**解决**：
1. 检查 MySQL 是否运行：`systemctl status mysql` 或 `docker-compose ps`
2. 检查数据库连接信息是否正确
3. 检查 MySQL 是否允许远程连接（如果使用云数据库）
4. 检查防火墙是否开放 3306 端口

### ❌ 问题 4：免费试用到期

**症状**：服务器无法访问

**解决**：
1. **续费**：在云服务器控制台续费（约 24-50元/月）
2. **迁移**：导出数据，迁移到其他免费服务器
3. **降配**：降低服务器配置以节省费用

## 💡 优化建议

### 1. 使用 Nginx 反向代理

```bash
# 安装 Nginx
apt install nginx -y

# 配置反向代理
nano /etc/nginx/sites-available/libra-bms
```

添加配置：
```nginx
server {
    listen 80;
    server_name 你的域名或IP;

    location / {
        proxy_pass http://localhost:8080;
        proxy_set_header Host $host;
        proxy_set_header X-Real-IP $remote_addr;
        proxy_set_header X-Forwarded-For $proxy_add_x_forwarded_for;
    }
}
```

```bash
# 启用配置
ln -s /etc/nginx/sites-available/libra-bms /etc/nginx/sites-enabled/
nginx -t
systemctl reload nginx
```

### 2. 配置 HTTPS（可选）

使用 Let's Encrypt 免费 SSL 证书：

```bash
# 安装 Certbot
apt install certbot python3-certbot-nginx -y

# 申请证书
certbot --nginx -d 你的域名
```

### 3. 配置域名解析

1. 在域名服务商（如阿里云、腾讯云）购买域名
2. 添加 A 记录：`@` → `你的服务器IP`
3. 等待 DNS 生效（约 10 分钟）
