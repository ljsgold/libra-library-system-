# 数据库诊断和修复步骤

## 🔍 快速诊断

### 方法一：在 Railway 中检查数据库表

1. **连接到 MySQL 数据库**：
   - 在 Railway 项目中，点击 **MySQL** 服务
   - 点击 **"Connect"** 标签页
   - 复制 **"原始命令 `mysql`"** 中的连接命令
   - 在终端中执行该命令

2. **检查表是否存在**：
```sql
USE libra_bms;
SHOW TABLES;
```

**预期结果**：应该看到以下表：
- `sys_tenant`
- `sys_user`
- `sys_role`
- `sys_menu`
- `sys_role_menu`
- `sys_user_role`
- `sys_log`
- `lib_book`
- `lib_inventory`
- `lib_borrow_record`
- `lib_config`
- `lib_category`
- `lib_reservation`

**如果表不存在**：继续执行步骤 2

## 🔧 修复步骤

### 步骤 2：执行数据库初始化脚本

1. **连接到 MySQL**（同上）

2. **执行初始化脚本**：
   - 打开项目中的 `db/init.sql` 文件
   - 复制**全部内容**
   - 在 MySQL 命令行中粘贴并执行

3. **验证表已创建**：
```sql
USE libra_bms;
SHOW TABLES;
```

应该看到 13 个表。

## 🐛 常见问题

### 问题 1：连接 MySQL 失败

**错误**：`command not found: mysql`

**解决**：
- Windows：下载 MySQL 客户端，或使用 Railway CLI
- Mac：`brew install mysql-client`
- Linux：`sudo apt-get install mysql-client`

### 问题 2：表已存在但仍有错误

**检查**：
```sql
USE libra_bms;
DESCRIBE sys_user;
```

确认表结构是否正确。

### 问题 3：执行 SQL 脚本时报错

**常见错误**：
- `Table already exists`：表已存在，可以忽略
- `Unknown database 'libra_bms'`：需要先创建数据库

**解决**：
```sql
CREATE DATABASE IF NOT EXISTS libra_bms DEFAULT CHARACTER SET utf8mb4 COLLATE utf8mb4_general_ci;
USE libra_bms;
-- 然后执行 init.sql
```
