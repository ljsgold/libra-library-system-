# 🔍 前端部署问题排查指南

## 🎯 问题：前端页面 ERR_CONNECTION_TIMED_OUT

如果前端页面无法打开，出现 `ERR_CONNECTION_TIMED_OUT` 错误，请按以下步骤排查：

---

## ✅ 第一步：检查 Vercel 部署状态

### 1.1 查看部署日志

1. 登录 Vercel Dashboard：https://vercel.com/dashboard
2. 进入项目：`libra-library-system-mga2`
3. 点击 **"Deployments"**（部署）标签页
4. 点击最新的部署记录
5. 查看 **"Build Logs"**（构建日志）

**检查点：**
- ✅ **构建成功**：日志显示 "Build Completed" 或 "✓ Build successful"
- ❌ **构建失败**：日志显示错误信息（TypeScript 错误、依赖安装失败等）

### 1.2 常见构建错误

#### 错误 1：TypeScript 类型错误
```
error TS2307: Cannot find module 'xxx'
```
**解决方案**：检查 `libra-frontend/src` 目录下的 TypeScript 文件是否有类型错误

#### 错误 2：依赖安装失败
```
npm ERR! code ERESOLVE
```
**解决方案**：检查 `libra-frontend/package.json` 中的依赖版本

#### 错误 3：构建命令错误
```
sh: npm: command not found
```
**解决方案**：检查 Vercel 项目设置中的 Node.js 版本

---

## ✅ 第二步：检查 Vercel 项目配置

### 2.1 确认项目根目录

**重要**：Vercel 需要知道项目根目录在哪里！

1. 在 Vercel Dashboard 中，进入项目设置
2. 点击 **"Settings"** → **"General"**
3. 检查 **"Root Directory"**（根目录）设置：
   - ✅ **如果前端代码在 `libra-frontend` 目录**：应该设置为 `libra-frontend`
   - ✅ **如果前端代码在项目根目录**：应该留空或设置为 `.`

### 2.2 检查构建配置

在 Vercel Dashboard 中，进入 **"Settings"** → **"General"** → **"Build & Development Settings"**：

- **Framework Preset**：应该选择 **"Vite"** 或 **"Other"**
- **Build Command**：
  - 如果根目录是 `libra-frontend`：`npm run build`
  - 如果根目录是项目根目录：`cd libra-frontend && npm run build`
- **Output Directory**：
  - 如果根目录是 `libra-frontend`：`dist`
  - 如果根目录是项目根目录：`libra-frontend/dist`
- **Install Command**：`npm install`

### 2.3 检查 vercel.json 配置

项目中有两个 `vercel.json` 文件：

1. **根目录的 `vercel.json`**：
```json
{
  "buildCommand": "cd libra-frontend && npm install && npm run build",
  "outputDirectory": "libra-frontend/dist",
  "framework": "vite",
  "installCommand": "cd libra-frontend && npm install"
}
```

2. **`libra-frontend/vercel.json`**：
```json
{
  "buildCommand": "npm run build",
  "outputDirectory": "dist",
  "framework": "vite"
}
```

**建议**：
- 如果 Vercel 项目根目录设置为 `libra-frontend`，使用 `libra-frontend/vercel.json`
- 如果 Vercel 项目根目录设置为项目根目录，使用根目录的 `vercel.json`

---

## ✅ 第三步：检查环境变量

### 3.1 确认环境变量已配置

1. 在 Vercel Dashboard 中，进入 **"Settings"** → **"Environment Variables"**
2. 确认存在以下变量：
   - **Name**: `VITE_APP_BASE_API`
   - **Value**: `https://libra-library-system-production.up.railway.app`
   - **Environment**: Production, Preview, Development（全部选中）

### 3.2 重新部署

**⚠️ 重要**：修改环境变量或配置后，必须重新部署！

1. 在 **"Deployments"** 标签页中
2. 找到最新部署，点击 **"..."** → **"Redeploy"**
3. 等待部署完成

---

## ✅ 第四步：检查 Node.js 版本

### 4.1 检查 package.json

在 `libra-frontend/package.json` 中，确认 Node.js 版本要求：
```json
{
  "engines": {
    "node": ">=20 <23"
  }
}
```

### 4.2 在 Vercel 中设置 Node.js 版本

1. 在 Vercel Dashboard 中，进入 **"Settings"** → **"General"**
2. 找到 **"Node.js Version"** 设置
3. 设置为 **20.x** 或 **22.x**

---

## ✅ 第五步：检查构建产物

### 5.1 查看构建输出

1. 在 Vercel Dashboard 中，进入 **"Deployments"** 标签页
2. 点击最新部署
3. 查看 **"Source"** 部分，确认构建产物是否存在：
   - `index.html`
   - `assets/` 目录（包含 JS、CSS 文件）

### 5.2 检查 index.html

如果构建成功但页面无法打开，可能是 `index.html` 路径问题。

在浏览器中直接访问：
```
https://你的前端地址/index.html
```

---

## ✅ 第六步：检查网络请求

### 6.1 使用浏览器开发者工具

1. 打开前端地址
2. 按 `F12` 打开开发者工具
3. 打开 **"Network"**（网络）标签页
4. 刷新页面
5. 查看请求：
   - **`index.html`**：应该返回 200
   - **`assets/*.js`**：应该返回 200
   - **`assets/*.css`**：应该返回 200

### 6.2 常见问题

- **所有资源都超时**：Vercel 部署有问题，检查构建日志
- **只有 API 请求超时**：环境变量未配置或后端无法访问
- **部分资源 404**：构建配置有问题，检查 `outputDirectory`

---

## 🔧 快速修复方案

### 方案 1：重新配置 Vercel 项目

1. **删除现有项目**（可选，如果问题严重）：
   - 在 Vercel Dashboard 中，进入项目设置
   - 滚动到底部，点击 **"Delete Project"**

2. **重新导入项目**：
   - 点击 **"Add New"** → **"Project"**
   - 选择你的 GitHub 仓库
   - **重要**：在 **"Configure Project"** 步骤中：
     - **Root Directory**：选择 `libra-frontend`
     - **Framework Preset**：选择 **"Vite"**
     - **Build Command**：`npm run build`
     - **Output Directory**：`dist`
   - 添加环境变量：`VITE_APP_BASE_API` = `https://libra-library-system-production.up.railway.app`
   - 点击 **"Deploy"**

### 方案 2：修复 vercel.json 配置

如果项目根目录是 `libra-frontend`，确保 `libra-frontend/vercel.json` 存在且配置正确：

```json
{
  "buildCommand": "npm run build",
  "outputDirectory": "dist",
  "framework": "vite",
  "rewrites": [
    {
      "source": "/(.*)",
      "destination": "/index.html"
    }
  ]
}
```

如果项目根目录是项目根目录，确保根目录的 `vercel.json` 存在且配置正确：

```json
{
  "buildCommand": "cd libra-frontend && npm install && npm run build",
  "outputDirectory": "libra-frontend/dist",
  "framework": "vite",
  "installCommand": "cd libra-frontend && npm install",
  "rewrites": [
    {
      "source": "/(.*)",
      "destination": "/index.html"
    }
  ]
}
```

- [ ] 浏览器开发者工具中，`index.html` 返回 200
