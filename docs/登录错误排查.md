# 🔧 登录页面"系统繁忙,请稍后再试"错误排查

## 🎯 错误原因

当登录页面显示"系统繁忙,请稍后再试"时，通常表示：

1. **前端无法连接到后端 API**（最常见）
2. **后端服务未运行或出现异常**
3. **环境变量配置错误**

---

## ✅ 快速排查步骤

### 第一步：检查 Vercel 环境变量配置（最重要！）

#### 1.1 检查环境变量是否存在

1. **登录 Vercel Dashboard**
   - 访问：https://vercel.com/dashboard
   - 进入项目：`libra-library-system-mga2`

2. **打开环境变量设置**
   - 点击左侧菜单 **"Settings"**（设置）
   - 点击 **"Environment Variables"**（环境变量）

3. **检查关键变量**
   - 查找变量名：`VITE_APP_BASE_API`
   - **如果不存在** = 这就是问题所在！需要添加

#### 1.2 获取后端地址

1. **登录 Railway**
   - 访问：https://railway.app
   - 进入你的后端项目

2. **获取后端域名**
   - 点击后端服务（不是 MySQL 服务）
   - 点击 **"Settings"** 标签页
   - 在 **"Domains"** 部分，找到后端域名
   - 格式：`https://xxx.railway.app` 或 `https://xxx.up.railway.app`

3. **复制完整地址**
   - ✅ 正确：`https://libra-backend-production.up.railway.app`
   - ❌ 错误：`https://xxx.railway.app/`（不要有末尾斜杠）
   - ❌ 错误：`http://xxx.railway.app`（必须是 https）

#### 1.3 配置环境变量

1. **在 Vercel 中添加环境变量**
   - 点击 **"Add New"**（添加新变量）
   - 填写：
     - **Name**: `VITE_APP_BASE_API`
     - **Value**: 粘贴你的 Railway 后端地址
     - **Environment**: **全选**（Production、Preview、Development）
   - 点击 **"Save"**（保存）

2. **重新部署前端**（重要！）
   - 点击 **"Deployments"** 标签页
   - 找到最新部署
   - 点击右侧 **"..."** → **"Redeploy"**
   - 等待部署完成（约 1-2 分钟）

---

### 第二步：检查后端服务状态

#### 2.1 检查 Railway 后端服务

1. **登录 Railway Dashboard**
   - 访问：https://railway.app
   - 进入你的项目

2. **检查服务状态**
   - 点击后端服务（不是 MySQL 服务）
   - 查看服务状态：
     - ✅ **"Running"**（绿色）= 正常运行
     - ❌ **"Stopped"** 或 **"Error"** = 服务未运行

3. **如果服务未运行**
   - 点击 **"Deployments"** 标签页
   - 查看部署日志，找出错误原因
   - 点击 **"Redeploy"** 重新部署

#### 2.2 测试后端是否可访问

在浏览器中直接访问：

```
https://你的后端地址/swagger-ui.html
```

- ✅ **能看到 Swagger 文档** = 后端正常运行
- ❌ **无法访问或超时** = 后端有问题

---

### 第三步：检查浏览器网络请求

#### 3.1 打开开发者工具

1. **访问前端登录页面**
   - 打开：https://libra-library-system-mga2.vercel.app/login

2. **打开开发者工具**
   - 按 `F12` 或右键 → **"检查"**
   - 打开 **"Network"**（网络）标签页

3. **尝试登录**
   - 输入账号密码
   - 点击登录按钮

#### 3.2 查看网络请求

在 Network 标签页中，查找 API 请求：

1. **检查请求 URL**
   - ✅ **正确**：`https://你的后端地址/api/auth/login`
   - ❌ **错误**：`https://libra-library-system-mga2.vercel.app/api/auth/login`（说明环境变量未配置）

2. **检查请求状态**
   - ✅ **200** = 请求成功
   - ❌ **ERR_CONNECTION_TIMED_OUT** = 无法连接到后端
   - ❌ **404** = 后端地址错误
   - ❌ **500** = 后端服务器错误

## 🔍 常见问题

### Q1: 环境变量已配置，为什么还是不行？

**A:** 环境变量修改后，**必须重新部署前端才能生效**！

1. 在 Vercel Dashboard 中，进入 **"Deployments"** 标签页
2. 找到最新部署，点击 **"..."** → **"Redeploy"**
3. 等待部署完成

### Q2: 如何确认环境变量是否正确？

**A:** 检查以下几点：

1. ✅ **变量名**：`VITE_APP_BASE_API`（必须完全一致）
2. ✅ **变量值**：`https://xxx.railway.app`（必须是完整的 HTTPS 地址）
3. ✅ **环境**：全选（Production, Preview, Development）
4. ✅ **已重新部署**：修改后已重新部署前端

### Q3: 后端服务显示 "Running"，但前端还是连不上？

**A:** 检查以下几点：

1. **后端地址是否正确**
   - 在浏览器中直接访问：`https://你的后端地址/swagger-ui.html`
   - 如果无法访问，说明后端地址有问题

2. **环境变量值格式是否正确**
   - ✅ 正确：`https://xxx.railway.app`（无末尾斜杠）
   - ❌ 错误：`https://xxx.railway.app/`（有末尾斜杠）

3. **是否已重新部署前端**
   - 修改环境变量后必须重新部署

### Q4: 浏览器显示 "ERR_CONNECTION_TIMED_OUT"？

**A:** 这表示前端无法连接到后端，可能原因：

1. **后端服务未运行**
   - 检查 Railway 服务状态
   - 查看部署日志

2. **环境变量未配置**
   - 检查 Vercel 环境变量
   - 确认已重新部署

3. **后端地址错误**
   - 确认 Railway 后端域名
   - 在浏览器中直接访问测试
