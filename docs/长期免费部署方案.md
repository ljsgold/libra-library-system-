## 🏆 方案一：Oracle Cloud 永久免费（最推荐）

### ✅ 为什么选择 Oracle Cloud？

- **♾️ 永久免费**：不是试用，是真正的永久免费套餐
- **配置不错**：2核 ARM CPU + 1GB RAM + 50GB 存储
- **流量充足**：10TB/月免费流量
- **完全够用**：可以运行 Spring Boot + MySQL + Redis

### 📦 免费资源详情

1. **Always Free 计算实例**：
   - 2 个 AMD 计算实例（每个 1/8 OCPU，1GB RAM）
   - 或 4 个 ARM 计算实例（每个 1 OCPU，1GB RAM）
   - **推荐选择 ARM**：性能更好

2. **存储**：
   - 200GB 块存储（免费）
   - 10GB 对象存储（免费）

3. **网络**：
   - 10TB/月 出站流量（免费）
   - 无限入站流量（免费）

### 🎯 注册步骤

1. **访问 Oracle Cloud**
   - 网址：https://www.oracle.com/cloud/free/
   - 点击 "Start for Free"

2. **注册账号**
   - 需要：邮箱、手机号、信用卡（**不会扣费**，仅用于验证）
   - 填写个人信息
   - 验证邮箱和手机号

3. **创建免费实例**
   - 登录后，进入 "Compute" → "Instances"
   - 点击 "Create Instance"
   - **重要配置**：
     - **Image**: Ubuntu 22.04
     - **Shape**: 选择 "VM.Standard.A1.Flex"（ARM 架构）
     - **OCPU**: 2
     - **Memory**: 12GB（免费额度内）
     - **Network**: 使用默认 VCN
     - **SSH Keys**: 上传你的 SSH 公钥（或让系统生成）

4. **配置安全组**
   - 进入 "Networking" → "Security Lists"
   - 添加入站规则：
     - **端口 22**（SSH）
     - **端口 8080**（应用）
     - **端口 3306**（MySQL，如果需要远程访问）
     - **端口 6379**（Redis，如果需要远程访问）

### 🚀 部署步骤

#### 步骤 1：连接服务器

```bash
# Windows 使用 PowerShell
ssh opc@你的服务器公网IP

# 如果是首次连接，会提示确认，输入 yes
```

#### 步骤 2：安装 Docker

```bash
# 更新系统
sudo yum update -y  # Oracle Linux
# 或
sudo apt update && sudo apt upgrade -y  # Ubuntu

# 安装 Docker
curl -fsSL https://get.docker.com -o get-docker.sh
sudo sh get-docker.sh

# 启动 Docker
sudo systemctl start docker
sudo systemctl enable docker

# 将当前用户添加到 docker 组（避免每次都用 sudo）
sudo usermod -aG docker opc

# 重新登录或执行
newgrp docker
```

#### 步骤 3：克隆项目并部署

```bash
# 安装 Git
sudo yum install git -y  # Oracle Linux
# 或
sudo apt install git -y  # Ubuntu

# 克隆项目
git clone https://github.com/你的用户名/libra-library-system-.git
cd libra-library-system-

# 启动服务
docker-compose up -d

# 等待 MySQL 启动后，初始化数据库
sleep 30
docker exec -i libra-db mysql -uroot -proot libra_bms < db/init.sql
```

#### 步骤 4：配置防火墙

```bash
# Oracle Cloud 使用 iptables 或 firewalld
# 检查防火墙状态
sudo firewall-cmd --state

# 开放端口（如果使用 firewalld）
sudo firewall-cmd --permanent --add-port=8080/tcp
sudo firewall-cmd --reload
```

### ⚠️ 注意事项

1. **国内访问速度**：
   - Oracle Cloud 免费套餐只有部分区域可选
   - 国内访问可能较慢，建议使用 CDN 或代理

2. **资源限制**：
   - 免费套餐有资源限制，不要超过配额
   - 如果超过，可能会被暂停或收费

3. **账户验证**：
   - 需要信用卡验证（不会扣费）
   - 如果 60 天内没有使用，可能会被回收

### 💰 费用

- **完全免费**：永久免费，不会产生任何费用
- **前提**：不要超过免费额度

## 🏠 方案五：本地部署 + 内网穿透（完全免费）

### ✅ 为什么选择本地部署？

- **完全免费**：使用你自己的电脑
- **性能好**：没有资源限制
- **完全控制**：所有数据都在本地

### 🎯 使用步骤

#### 步骤 1：本地部署应用

按照项目文档在本地运行：
```bash
# 使用 Docker
docker-compose up -d

# 或手动部署
mvn clean package
java -jar libra-admin/target/libra-admin.jar
```

#### 步骤 2：配置内网穿透

**选项 A：使用 ngrok（推荐，最简单）**

1. **注册 ngrok**
   - 访问：https://ngrok.com
   - 注册免费账号

2. **下载并安装**
   ```bash
   # Windows
   # 下载：https://ngrok.com/download
   # 解压到任意目录
   ```

3. **启动 ngrok**
   ```bash
   # 在 ngrok 目录下执行
   ngrok authtoken 你的token
   ngrok http 8080
   ```

4. **获取公网地址**
   - ngrok 会显示一个公网地址，如：`https://xxxx.ngrok.io`
   - 这个地址会转发到你的本地 8080 端口

**选项 B：使用 frp（免费，需要服务器）**

如果你有其他免费服务器，可以使用 frp 做内网穿透。

**选项 C：使用 ZeroTier（免费，P2P VPN）**

1. **注册 ZeroTier**
   - 访问：https://www.zerotier.com
   - 创建免费网络

2. **安装 ZeroTier**
   - 在本地电脑和需要访问的设备上安装 ZeroTier
   - 加入同一个网络

3. **通过内网 IP 访问**
   - 使用 ZeroTier 分配的内网 IP 访问应用

### ⚠️ 注意事项

1. **电脑需要开机**：应用只在电脑运行时可用
2. **网络稳定性**：依赖本地网络稳定性
3. **安全性**：确保防火墙配置正确

### 💰 费用

- **完全免费**：所有工具都有免费套餐

### 🚀 方案一：Vercel（最推荐，永久免费）

#### ✅ 为什么选择 Vercel？

- **♾️ 永久免费**：不是试用，是真正的永久免费
- **自动部署**：连接 GitHub，每次推送自动部署
- **全球 CDN**：自动分发到全球节点
- **零配置**：支持 Vue、React、Next.js 等，自动识别
- **自定义域名**：免费提供自定义域名支持
- **预览部署**：每个 PR 自动生成预览链接

#### 📦 免费资源详情

- **无限部署**：不限部署次数
- **100GB 带宽/月**：通常够用
- **无限项目**：可以部署多个项目
- **团队协作**：支持团队功能（免费版有限制）

#### 🎯 部署步骤（5 分钟完成）

1. **注册 Vercel**
   - 访问：https://vercel.com
   - 使用 GitHub 账号登录（推荐）

2. **导入项目**
   - 点击 "Add New" → "Project"
   - 选择你的 GitHub 仓库
   - 如果前端在子目录（如 `libra-frontend`），设置：
     - **Root Directory**: `libra-frontend`
     - **Framework Preset**: `Vite`（自动识别）
     - **Build Command**: `npm run build`（自动识别）
     - **Output Directory**: `dist`（自动识别）

3. **配置环境变量**
   - 在项目设置中添加环境变量：
     - **Name**: `VITE_APP_BASE_API`
     - **Value**: `你的后端地址`（如：`https://xxx.railway.app`）
     - **Environment**: Production, Preview, Development（全选）

4. **部署**
   - 点击 "Deploy"
   - 等待部署完成（通常 1-2 分钟）
   - 获得免费域名：`https://你的项目名.vercel.app`

#### ⚠️ 注意事项

1. **国内访问**：
   - Vercel 在国内访问可能较慢或不稳定
   - 如果国内访问有问题，推荐使用 **Cloudflare Pages**

2. **环境变量**：
   - 修改环境变量后需要重新部署
   - 环境变量以 `VITE_` 开头才能在构建时使用

3. **路由配置**：
   - 项目已包含 `vercel.json` 配置，支持 Vue Router
   - 如果路由有问题，检查 `vercel.json` 中的 `rewrites` 配置

#### 💰 费用

- **完全免费**：永久免费，不会产生任何费用
- **前提**：不要超过免费额度（通常个人项目不会超过）
